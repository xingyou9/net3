    01 / Overview

    总览：三年怎么拆，毕业时要成为什么样的人

    三年不是“上课—考试—毕业”，而是三个能力台阶。每一年都有明确的输出物，缺一项都会在毕业时暴露。

    大一

    地基年：把散装知识变成体系

    核心任务：网络基础 + 路由交换入门 + 第一张证书 + 摸清学校资源。

    • 输出物 1：eNSP 实验仓库 ≥ 20 个拓扑
    • 输出物 2：1+X 网络系统建设与运维（中级）
    • 输出物 3：综合测评排名稳定在前 60%（专升本生命线）
    • 输出物 4：英语学习不断线
    关键认知：大一最值钱的不是成绩，是把动手习惯养出来。这一年没进过实训室的人，后面很难补。
    大二

    分化年：拉开身位的决定性一年

    核心任务：HCIA + Linux + Python + 竞赛 + 软考职称证书。

    • 输出物 1：华为 HCIA-Datacom
    • 输出物 2：软考《网络工程师》中级职称证书
    • 输出物 3：一次完整项目文档（拓扑+配置+验收）
    • 输出物 4：至少一次省级/校级竞赛经历
    • 输出物 5：HCIP 至少 1 门 + 锁定实习
    关键认知：大二下是三年里最不能浪费的半年。这一年决定你是“普通毕业生”还是“被提前锁定的人”。
    大三

    收割年：把积累兑换成结果

    核心任务：分流执行（就业 / 专升本 / 参军），并完成收割。

    • 就业派：实习 ≥ 6 个月 + 秋招 + 春招谈薪
    • 升本派：3 月下旬统考 + 70 个平行志愿填报
    • 共同：毕业设计做真项目，一稿两用
    • 共同：证书、档案、党团关系、三方协议逐项核对
    关键认知：这一步的核心是不犯错，而不是再学新东西。所有关键节点都有窗口期，错过无法补。

    ⚖️ 岗位红绿灯：把自己放到绿灯区

    🔴 红灯区（正在被压缩，别往这挤）
    • 纯盯屏告警监控 / 机械式日志巡检
    • 只会用扫描器跑一遍的“初级渗透”
    • 照模板填表的合规文档专员
    • 只会拉网线、配 VLAN 的基础网管
    • 没有自动化能力、纯手工重复操作的运维

    依据：约 90% 的低危告警已可由自动化处置；初级岗位招聘增速（约 5.9%）远低于高级岗位（约 65%）。

    🟢 绿灯区（需求增长，往这走）
    • 能独立定位并闭环复杂故障的网络工程师
    • 云网融合：懂网络 + Linux + 云平台的复合运维
    • 信创国产化：国产 OS、国产设备、等保合规运维
    • 全光网 / 无线 / IPv6 新建与改造项目能力
    • 自动化运维（Python / Ansible）与 AIOps 工具素养
    • 安全运营、数据安全治理、云安全架构（中高级）

    依据：企业反馈紧缺技能集中在实战攻防、关基运维、AI 安全、数据安全治理与安全合规；招聘最看重工作经验（76.2%）与实战能力（72.2%）。

    08 / Year 3

    大三怎么安排：四条路的完整决策

    大二下必须选定一条主路径 + 一条兜底路径。四条路的时间成本互斥，全抓等于全不精。

    🧭 决策树：30 秒定位你的主路径

    你的情况建议主路径理由兜底
    家庭需要你尽快有收入 / 已有实习 offer / 动手意愿强路径 A：直接就业行业经验溢价最明显，早三年入行 = 早三年积累故障库自考/成人本科保住学历通道
    综合测评前 60%，或已获省赛三等奖及以上路径 B：专升本校荐生录取率约 53%，能打开国企/运营商/事业单位本科门槛秋招必须参加，手握 offer
    综合测评未进前 60% 且无竞赛奖项路径 A（优先）/ B（走自荐）自荐生需参加高校专业测试，录取率约 30%，成本高先就业，次年再评估
    体格达标 + 有参军意愿路径 C：参军 → 免试专升本退役大学生士兵免文化课统考，单独计划单独划线保持技术阅读，避免完全断档
    还没想清楚 / 成绩中等 / 无明确偏好路径 A + B 并行到大二下再定大一、大二的准备工作（排名、证书、竞赛）对两条路都有用大二下必须拍板，不能再拖
