    01 / Overview

    总览：三年怎么拆，毕业时要成为什么样的人

    三年不是“上课—考试—毕业”，而是三个能力台阶。每一年都有明确的输出物，缺一项都会在毕业时暴露。

    大一

    地基年：把散装知识变成体系

    核心任务：网络基础 + 路由交换入门 + 第一张证书 + 摸清学校资源。

    • 输出物 1：eNSP 实验仓库 ≥ 20 个拓扑
    • 输出物 2：1+X 网络系统建设与运维（中级）
    • 输出物 3：综合测评排名稳定在前 60%（专升本生命线）
    • 输出物 4：英语学习不断线
    关键认知：大一最值钱的不是成绩，是把动手习惯养出来。这一年没进过实训室的人，后面很难补。
    大二

    分化年：拉开身位的决定性一年

    核心任务：HCIA + Linux + Python + 竞赛 + 软考职称证书。

    • 输出物 1：华为 HCIA-Datacom
    • 输出物 2：软考《网络工程师》中级职称证书
    • 输出物 3：一次完整项目文档（拓扑+配置+验收）
    • 输出物 4：至少一次省级/校级竞赛经历
    • 输出物 5：HCIP 至少 1 门 + 锁定实习
    关键认知：大二下是三年里最不能浪费的半年。这一年决定你是“普通毕业生”还是“被提前锁定的人”。
    大三

    收割年：把积累兑换成结果

    核心任务：分流执行（就业 / 专升本 / 参军），并完成收割。

    • 就业派：实习 ≥ 6 个月 + 秋招 + 春招谈薪
    • 升本派：3 月下旬统考 + 70 个平行志愿填报
    • 共同：毕业设计做真项目，一稿两用
    • 共同：证书、档案、党团关系、三方协议逐项核对
    关键认知：这一步的核心是不犯错，而不是再学新东西。所有关键节点都有窗口期，错过无法补。

    02 / Priority

    学习优先级：先练什么，后考什么

    这一节回答的是最容易被搞反的问题——证书不是大学三年的核心任务，能力才是。下面的分级依据是「岗位 JD 出现频次 × 可验证性 × 迁移性」，不是个人偏好。每一级都给了验收标准，达不到标准就不算掌握。

    必须接受的现实：考到证书 ≠ 具备企业需要的实际工作能力。如果花大量时间背题拿证，却不会配设备、不会排故障、不会部署 Linux 服务，那么简历上堆再多证书，面试时第一个深挖问题就会露底。 宁可少考一张证，也要保证自己真正做过两个能在面试里讲清楚的项目。
    使用方法：先看 S 级，逐条对照自己的验收标准——能做到「独立完成」或「能排障」，才算过关。S 级有四条没到位的，先别碰 A 级和 B 级。证书只在 B 级之后才进入考虑范围。

    08 / Projects

    项目实战：三层递进，每层都要交东西

    20 个实验拓扑证明不了就业能力，一个完整交付可以。三层项目按「基础网络 → 系统与服务 → 综合方案」递进，每层都列了必须交付的成果，勾选即记录完成度。

    09 / Environment

    环境与工具：把练习场搭起来

    工具不是目的，但没有合适的工具，很多练习根本做不了。先把免费软件装齐、确认自己能坚持练，再考虑买硬件——这是避免浪费钱的最简单办法。

    关于模拟器的重要提醒：华为 eNSP 官方已停止更新，在 Win11 + 新版 VirtualBox 环境下经常启动失败，这是几乎所有初学者都会踩的坑。建议主用 HCL（新华三） 或 EVE-NG，eNSP 只作为查阅 HCIA 教学资料的补充。命令体系有差异，但原理完全相通。

              模块四 · 欧洲求职：三条签证路径的真实条件

              2026 官方口径

              所有薪资门槛都是税前年毛收入，且每年 1 月调整。下面数字为 2026 年官方公布值，你执行时必须重新核对—— 这类门槛近年一直在涨，按今年的线做的规划，三年后可能不够。

              六国横向对比：不是「哪国好」，是「哪国进得去」

              为什么把德国放第一：不只是岗位多。真正的原因是——只有德国的法规里明确写了「IT 专家无学历 + 3 年经验可申请蓝卡」。 其他国家要么明文要求学位（爱尔兰关键技能签证），要么虽然不要求学历但薪资门槛高到 Junior 岗进不去（荷兰）。 这是制度差异，不是努力能弥补的。
